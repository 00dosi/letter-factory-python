# 개발 문서 (인수인계)

이 저장소는 레터팩토리 뉴스레터 제작 엔진의 **파이썬 원본**이다. 2026-10 부터 레터팩토리 플랫폼은 TypeScript 로 옮겨 가고 있고(별도 비공개 저장소), 이 엔진은 그 이식의 **동작 기준**과 골든 테스트(같은 입력 → 같은 출력)의 정답지로 남아 있다.
새 기능 개발 · 고도화는 TS 플랫폼에서 한다. 여기서는 기준 동작을 고칠 때만 손댄다.

| 문서 | 내용 |
|---|---|
| [development.md](development.md) | 필요한 도구 · 버전, 설치, `.env` 항목 이름, 테스트 · 실행 명령(직접 돌려 본 결과) |
| [architecture.md](architecture.md) | 모듈별 역할, 호 하나의 데이터 흐름, 데이터 폴더 · 파일 형식, MCP 서버 |
| [status.md](status.md) | 결정 기록, 알려진 문제, 남은 일 |

사용자용 설치(Claude 데스크톱 · Cowork MCP 연결), MCP 도구 표, `draft.md` 형식, 템플릿 설명은 루트 [`README.md`](../README.md) 에 있다. 여기서 다시 쓰지 않는다.

이 저장소는 **공개**다. 고객 설정 · 호 데이터 · API 키 · 계정 정보는 커밋하지 않는다(코드만 있고, 데이터는 별도 데이터 폴더에 둔다).
