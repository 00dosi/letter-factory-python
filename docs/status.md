## 알려진 문제

- **Python 3.10 · 3.11 에서 `lf/stibee.py` 문법 오류.** 52행 f-string 안의 `rf'<{t}\b'` (역슬래시) 는 3.12 부터 된다. `pyproject.toml` · `mcp_server.py` 의 `requires-python = ">=3.10"` 과 맞지 않는다. 고치려면 정규식을 f-string 밖 변수로 빼거나 `requires-python` 을 `>=3.12` 로 올린다. (사용자 PC 의 `uvx` 가 어떤 파이썬을 고르는지: 확인 필요)
- 의존성 버전이 고정돼 있지 않다(`requests` 등). 설치 시점에 따라 동작이 달라질 수 있다.
- lint · CI 가 없다. 테스트는 사람이 돌린다.
- 인증서가 깨진 공공 사이트는 `verify=False` 로 열고, 옛 TLS 사이트는 보안 수준을 낮춰 연다(`legacy_tls`). TS 플랫폼(Workers)에서는 이것이 안 돼 같은 결과가 나오지 않는다.
- 일부 국내 게시판은 해외에서 접속하면 막힌다(2026-10-07 시험). 해외 서버에서 돌리면 수집 결과가 달라진다.
- `holidays_kr.yaml` 에 없는 해는 영업일 계산에서 공휴일을 모른다.
- 네이버 관련 모듈(`naver_news` · `blog`)은 코드에 남아 있지만 레터팩토리 결정으로 쓰지 않는다.
